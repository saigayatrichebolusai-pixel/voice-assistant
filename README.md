# 🎙️ Voice Assistant

A simple and user-friendly **Voice Assistant developed using Python**. The project allows users to interact with the computer using voice commands and perform various tasks such as searching the web, opening applications, telling the time, and responding to basic queries.

## 📌 Project Description

The Voice Assistant is a Python-based application designed to provide a simple voice-controlled interface. It listens to the user's voice through a microphone, processes the spoken command, and performs the requested action.

The project is suitable for beginners and demonstrates important Python programming concepts such as **variables, functions, conditional statements, loops, user input, exception handling, and external Python libraries**.

## ✨ Features

* 🎙️ Accept voice commands from the user
* 🗣️ Convert speech into text
* 🔊 Provide responses using text-to-speech
* 🌐 Search information on the internet
* 🕐 Tell the current time
* 📅 Tell the current date
* 🎵 Play music or audio
* 🌍 Open websites
* 💻 Perform basic computer tasks
* ❌ Exit the assistant using a voice command
* 🖥️ Simple and user-friendly interface

## ▶️ How to Run

### 1. Install Python

Make sure **Python 3** is installed on your computer.

### 2. Clone the Repository


## 🎯 How It Works

1. Launch the Voice Assistant.
2. The program activates the microphone.
3. The assistant listens to the user's voice command.
4. The speech is converted into text.
5. The program identifies the requested command.
6. The corresponding task is performed.
7. The assistant provides a voice response.
8. The process continues until the user asks the assistant to exit.
